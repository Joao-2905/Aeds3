Backup Completo do Sistema

Backup normal

Cria um arquivo único com todos os arquivos binários da pasta data. Esse arquivo serve como base para a compactação com Huffman e LZW.

Arquivos envolvidos

  • user.bin, film.bin, genre.bin, review.bin e film_genre.bin
  • Arquivos de Hash Extensível: diretorios e buckets
  • Listas invertidas dos relacionamentos
  • Arquivo da Árvore B+ de avaliações por nota

Compressão Huffman

Compactar com Huffman

Gera o backup normal e depois compacta o arquivo usando o algoritmo de Huffman.

Restaurar Huffman

Descompacta o arquivo Huffman e restaura todos os arquivos binários na pasta data_restaurada_huffman.

Compressão LZW

Compactar com LZW

Gera o backup normal e depois compacta o arquivo usando o algoritmo LZW.

Restaurar LZW

Descompacta o arquivo LZW e restaura todos os arquivos binários na pasta data_restaurada_lzw.
